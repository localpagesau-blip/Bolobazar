### Vague Quantity Handling — Quick Reference

| Customer Says | Agent Should Ask |
|---|---|
| "Thoda sa" | "Roughly kitna chahiye — jaise ek kilo, do kilo, ya aadha kilo?" |
| "Do-teen kg" | "Theek teen kilo ya do kilo? Bataaiye." |
| "Thode se" (countable) | "Kitne chahiye — do, teen, chaar?" |
| "Kuch" / "Kuch items" | "Kya lena chahenge? Jaise — sabzi, dal, ya koi aur cheez?" |
| "Do-char" | Prompt for exact number |
| "Jo bhi mile" | "Aap bataaiye, kaunsi specific cheez chahiye?" |

## 12. Common Code-Switching Patterns (Hinglish)

Customers naturally mix English and Hindi. The agent should handle these common patterns:

| Pattern | Example | How Agent Should Respond |
|---|---|---|
| English noun + Hindi quantity | "Rice do kilo" | "2 kilo chawal — sahi hai?" |
| Hindi sentence + English item | "Mujhe ek bread loaf chahiye" | "1 loaf bread — kaunsa brand? Brown ya white?" |
| English sentence, Hindi item | "I need some haldi and dhaniya" | "Haldi aur dhaniya — kitna chahiye?" |
| Hindi verb + English noun | "Mujhe order karna hai milk powder" | "Milk powder — kitne grams?" |
| English filler + Hindi content | "Yes, so, ek kilo toor dal do" | "1 kilo toor dal — sahi hai. Aur kuch?" |
| English wrapper, Hindi core | "I want 2 kg aata and 1 litre tel" | "2 kilo aata aur 1 litre tel — sahi hai?" |
| "Sirji" / "Madamji" + Hindi | "Sirji, ek packet namkeen de do" | "1 packet namkeen — sahi hai." |

## 13. Automatic Language Detection Rules

| Clue | Language to Use | Trigger |
|---|---|---|
| Customer starts with "Haan", "Namaste", "Kya" | Hindi / Hinglish | Default |
| Customer starts with "Hello" then Hindi | Hinglish | Match mix |
| Customer says "Hello?" then full English sentence | English | Switch entirely |
| Customer uses pure English after Hindi greeting | English | Switch at next turn |
| Customer uses "ji" suffix | Hindi / Hinglish | Respectful form |
| Customer says "Yaar", "Bhai" | Casual Hinglish | Maintain casual |
| Customer uses pure Sanskritized Hindi | Pure Hindi | Avoid English words completely |
